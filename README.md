# موقع كتالوج منتجات + لوحة تحكم (Next.js على Vercel)

## وش فيه
- **الموقع**: الرئيسية، جميع المنتجات (مع بحث)، صفحة لكل قسم، صفحة لكل منتج، تواصل معنا.
- **لوحة التحكم** على `/admin`: المنتجات، الأقسام، رسائل الزوار، إعدادات الموقع (الاسم، الشعار، اللون، النصوص، بيانات التواصل).

## النشر على Vercel

### 1) ارفع الملفات على GitHub
1. سجّل في https://github.com ثم أنشئ مستودع جديد (New repository) واجعله Private.
2. اضغط "uploading an existing file" واسحب **محتويات** هذا المجلد كلها (مو المجلد نفسه)، ثم Commit.

### 2) اربطه بـ Vercel
1. سجّل في https://vercel.com بحساب GitHub.
2. Add New > Project > اختر المستودع > Deploy.

### 3) اربط قاعدة البيانات والصور
من صفحة المشروع في Vercel افتح تبويب **Storage**:
1. أنشئ قاعدة **Upstash Redis** (من Marketplace) واربطها بالمشروع. (لحفظ المنتجات والإعدادات والرسائل)
2. أنشئ **Blob** store واربطه بالمشروع. (لرفع الصور)

Vercel يضيف المتغيرات تلقائياً (`KV_REST_API_URL`, `KV_REST_API_TOKEN`, `BLOB_READ_WRITE_TOKEN`).

### 4) كلمة مرور لوحة التحكم
Settings > Environment Variables > أضف:
- الاسم: `ADMIN_PASSWORD`
- القيمة: كلمة مرور قوية وطويلة

### 5) أعد النشر
Deployments > آخر نشر > ⋯ > **Redeploy** (عشان تتفعل المتغيرات).

بعدها ادخل على `رابط-موقعك/admin`.

## ربط الدومين
1. في Vercel: Settings > **Domains** > اكتب دومينك > Add.
2. Vercel يعرض لك سجلات DNS المطلوبة (سجل A للدومين الرئيسي و CNAME لـ www).
3. ادخل لوحة الشركة اللي شاري منها الدومين، وأضف السجلات نفسها في إعدادات DNS.
4. انتظر التفعيل (غالباً دقائق، وأحياناً لين 24 ساعة). شهادة SSL تتفعل تلقائياً.

## التشغيل على جهازك (اختياري)
```
npm install
npm run dev
```
بدون ربط قاعدة البيانات يظهر الموقع ببيانات تجريبية ولا تُحفظ التعديلات.
